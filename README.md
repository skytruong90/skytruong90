# David Tan

**Software Engineer — Aerospace & Defense** · Huntsville, AL

I build the simulation and flight-software infrastructure that missile and space programs depend on: C++17 six-degree-of-freedom flight dynamics models, guidance and control algorithms, and the CI/CD pipelines that keep them verifiable.

`Active Secret clearance · TS eligible`

## What I work on

- **6-DOF flight dynamics simulation** — rigid-body propagation, aerodynamic modeling, autopilot and airframe coupling, Monte Carlo dispersion analysis in C++17.
- **Guidance, navigation & control** — proportional and augmented proportional navigation, surrogate autopilot models, state estimation, and the trade studies that decide which fidelity level a program actually needs.
- **Simulation infrastructure** — build systems, regression harnesses, and CI/CD pipelines that turn one-off analyst models into repeatable, version-controlled engineering artifacts.

Programs: LGM-35A Sentinel · FORGE OPIR · Hydra-70 / APKWS

## Selected work

### [Missile 6-DOF Flight Simulation](https://github.com/skytruong90) <!-- update link when published -->
Standalone C++17 six-degree-of-freedom missile flight dynamics simulation. Rigid-body equations of motion, autopilot, PN/APN guidance laws, and Monte Carlo dispersion runs with configurable atmosphere and aero decks.

`C++17` · `Flight Dynamics` · `Monte Carlo`

### [SentinelScore](https://github.com/skytruong90/SentinelScore)
C++17 threat prioritization engine built for mission-critical latency budgets. Ranks incoming tracks against a configurable scoring model with deterministic, testable behavior under load.

`C++17` · `Real-Time Systems` · `Threat Prioritization`

### [Airgap-Bundler](https://github.com/skytruong90/airgap-bundler)
Secure file packaging for air-gapped environments. Generates manifests, strips EXIF metadata, runs AV scanning, and produces cryptographic verification for transfers into and out of isolated networks.

`Python` · `Cryptographic Verification` · `Air-Gap Transfer`

### [Supersonic Monorepo Tools](https://github.com/skytruong90/supersonic-tools)
Bash and Git automation for large modular monorepos. Handles submodule orchestration, branch hygiene, and multi-team workflows in restricted environments where standard tooling isn't available.

`Bash` · `Git Automation` · `Monorepo`

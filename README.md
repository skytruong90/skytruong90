### 🚀 [Missile Flight Dynamics Simulation](https://github.com/skytruong90/Missile_Flight_Dynamics_Simulation)

A standalone **C++17 multi-rate 6-DOF flight simulation** with quaternion attitude dynamics, autopilot control, seeker modeling, and deterministic Monte Carlo dispersion analysis.

**Highlights**
- 48 automated unit and validation checks
- proportional navigation, augmented PN, and pursuit guidance
- single-run and Monte Carlo execution modes
- CSV outputs for trajectory and analysis workflows

### 📡 [SentinelTrack](https://github.com/skytruong90/sentineltrack)

A **distributed radar and multi-sensor tracking simulation** with noisy detections, UDP networking, Extended Kalman filtering, track management, and mission visualization.

**Highlights**
- 44 automated tests
- multi-process architecture with live networking
- packet loss, clutter, and noisy measurement handling
- track association and lifecycle management

</td>

### 🛡️ [Adversarial Resilience Testbed](https://github.com/skytruong90/Adversarial_Resilience_Testbed)

A **fault-injection and resilience testbed** that red-teams a guidance loop with spoofing, jamming, replay, and drift attacks, then evaluates defensive anomaly-detection behavior.

**Highlights**
- defended vs. undefended performance comparisons
- detection latency and false-alarm metrics
- simulation-driven security engineering
- lightweight estimator and integrity-monitor design

</td>

### 🌍 [Atmospheric Reentry Simulator](https://github.com/skytruong90/Atmospheric-Reentry-Simulator)

A documented **C++17 atmospheric-entry simulator** featuring layered atmosphere modeling, Mach-dependent drag, heating estimation, and RK4 integration.

**Highlights**
- 1976 Standard Atmosphere approximation
- convective heating estimation
- analysis-ready CSV outputs
- clean separation between library, CLI, and tests
